# Security Policy

## Reporting a Vulnerability

Please report security issues privately to the maintainers. Do not open a
public issue for a vulnerability.

Preferred: GitHub Security Advisories → **Report a vulnerability**.

If that is unavailable, email `security@autokeren.com` with:

- affected component (`engine/` or `runtime/`)
- affected version
- reproduction steps or proof of concept
- impact assessment

## Response

Maintainers will acknowledge within 3 business days and aim to publish a
fix or advisory for confirmed issues. Public discussion happens after the
fix ships.

## Out of scope

The project is intended for legitimate browser automation: testing,
accessibility, scraping public data with permission, and research. Abuse of
the anti-detect engine to bypass anti-fraud systems, evade bot detection on
services you are not authorized to access, or conduct credential-stuffing is
out of scope and not supported.
