Built for the Way Agents Actually Work

Most agent browsers are blind. Ghostfox gives your AI semantic understanding — not just pixel coordinates or fragile CSS selectors.

👁️

Semantic Vision

page_a11y sees every element with its role, name, and live value — piercing shadow DOM and iframes. Your agent understands the page, not just scrapes it.

🧠

Session Awareness

login_state in every snapshot. Your agent detects dead sessions before acting, not after failing. No more blind automation on expired cookies.

🖱️

Act by Understanding

page_click_ref e38 — no selectors, no guessing. Click "Post", type into "Title", because the agent reads what's there, not what a scraper hardcoded.

🥷

Stealth That Works

Fingerprint spoofing at the C++ level inside our own Firefox fork. Navigator, fonts, WebGL, WebRTC, timezone — all coherent, all audited. 500/500 identity coherence.

📹

Evidence Recording

Every session writes an append-only event log, page snapshots, screenshots, and the identity used. Replay what your agent did — line by line. Enterprise-grade audit trail.

📱

Android Personas

Touch points patched at the C++ level (dead in upstream), coarse pointer, portrait viewports. A phone identity that reads like a phone — because it is one.

🦀

Rust-Native Runtime

Single binary. Speaks Firefox's Juggler protocol directly. Zero Python, zero Node at runtime. pip install ghostfox or npx ghostfox — your choice.

🔓

You Own Everything

Engine fork + runtime — both yours, both open source. Your agent's cookies and identities never touch a third-party cloud. Self-hosted sovereignty.

⏱️

Smart Waiting

page_wait_for replaces sleep-guessing. Your agent waits for what matters — a button to appear, a form to load — then acts. No more sleep(8).

See What the Agent Actually Sees

One page_a11y call returns the full semantic picture. No guessing, no brittle selectors, no blind automation.

// agent: page_a11y() returns:
{
  "login_state": "logged-in",
  "page_title": "Submit to r/SideProject",
  "elements": [
    { "ref": "e21", "role": "textbox", "name": "Title" },
    { "ref": "e8",  "role": "textbox", "name": "Post body text field" },
    { "ref": "e38", "role": "button", "name": "Post" }
  ]
}

// agent: act by ref, no selectors
page_type_ref("e21", "My launch post...")
page_type_ref("e8",  "Body text here...")
page_click_ref("e38")  // Post → done
